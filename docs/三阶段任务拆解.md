## 🟢 Now（v1.2，0–3 个月）— 把闭环做真、把信任做硬

### Now-① CORS 配置修复（代码事实 #1）✅
- [x] `api.go` 中间件：`Allow-Origin:*` + `Allow-Credentials:true` 改为**按需反射 Origin**，消除浏览器拒绝。
- [x] 验证：`curl -I` 带 `Origin` 头确认返回正确 `Access-Control-Allow-Origin`。

### Now-② 演示数据标注与空状态引导（F3 + 部分 F11）✅
- [x] `store.seed()`：仅在**全新空库**时写入 `meta(demo_data)='1'`。
- [x] `store.MarkOnboarded()`：用户首次新增标的时清除 `demo_data` 标记、置 `onboarded=1`。
- [x] `api/auth/status` 返回 `demo` 字段。
- [x] 前端 `store.js` 读取 `demo`；`DashboardView.vue` 顶部展示**演示数据横幅**与"去添加我的标的"入口。

### Now-③ 实时刷新性能优化（F4，服务端侧）✅
- [x] `core.GlobalSummaryCached()`：3s TTL 内存缓存，避免 SSE tick 触发的高频全量重算风暴。
- [x] `api/dashboard/summary` 改用缓存版；后续再做前端增量合并（Next 阶段）。

### Now-④ 真实 SMTP 邮件提醒（F1 / P1）✅
- [x] `alerts.go`：`sendMailReal()` 基于 `net/smtp`，支持 465 隐式 TLS / 587 STARTTLS / 明文；`fire()` 邮件通道改调真实发送。
- [x] 新增设置键：`smtp_host / smtp_port / smtp_from / smtp_to / smtp_user / smtp_pass(加密) / smtp_tls`。
- [x] `POST /settings/mail-test` 端点 + `alerts.SendTestMail()`。
- [x] `SettingsView.vue` 新增「邮件提醒(SMTP)」卡片 + 发送测试邮件按钮；`api.js` 加 `mailTest`。

### Now-⑤ 跨币种聚合修复（代码事实 #2）✅
- [x] `core.aggregate()` 已改为：先统计各币种数量取**主币种（dominant）**，再用 `Convert()` 把每个 item 金额换算到主币种后求和。`GlobalSummary` 的 sub→main 转换不再传播错误。
- [x] 验证：临时建 CNY 加密货币 + 既有 USD 加密货币，subtotal.currency 自动选 USD 且市值与手算一致；dashboard 类目(CNY) = subtotal×7.2 与实时一致。测试资产已清理。
- [ ] 进阶：引入 `fx_rates` 表/外部汇率源（见 Next-②），让汇率可配置而非写死 7.2。

### Now-⑥ 行情映射透明度（F2 第一批）✅
- [x] 后端 `Quote.Status` 已发 `ok|sim|stale`；`PositionView.QuoteStatus` 与前端 `store.live()` 已透传。
- [x] `PositionsView.vue` + `AssetDetailView.vue`：价格旁徽标 `sim`→「模拟」、`stale`→「行情失效」(`.tag.warn`)；`styles.css` 补 `.tag.warn`。
- [x] 验证：built chunk 含 `quoteStatus==="stale"` 分支与「行情失效」文案。
- [ ] 进阶：Dashboard 汇总层也展示「部分行情为模拟/失效」的全局提示（见 Next-①）。
